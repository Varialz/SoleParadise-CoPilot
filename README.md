# Sole Paradise — Shopify Theme

Sole Paradise is a Chicago-based luxury and designer resale storefront built from the proven commerce architecture of `Varialz/LacedUpChicago-CoPilot`, with a separate Sole Paradise visual and motion system.

## Art direction

**Chicago Riviera** — crisp white merchandising space, cobalt blue accents, editorial scale, archive-style product presentation, and restrained GSAP motion. The system is intentionally designed to make mixed studio and phone-shot resale inventory feel cohesive.

## Current foundation

- Shopify OS 2.0 JSON templates
- Responsive header + mobile drawer
- Footer + newsletter + social links
- Canonical product cards and pricing
- Product gallery, variants, safe Add to Cart fallback
- Collection grid + sorting + pagination
- Sole Paradise homepage sections
- GSAP + ScrollTrigger motion layer
- White / cobalt Sole Paradise theme defaults

## Homepage sections

- `sp-hero.liquid` — editorial campaign hero
- `sp-trust-strip.liquid` — authenticity / service proof
- `sp-featured-collection.liquid` — Freshly Landed products
