# Sole Paradise — Real Asset Shot List

The launch demo should not rely on AI-generated campaign art or generic theme placeholders. The theme is intentionally built so real Shopify product photography carries most of the storefront.

## P0 — assets needed for the demo

### 1. Homepage hero — desktop
- 1 real photograph
- landscape, ideally 3:2 or 16:10
- minimum ~2000px wide
- leave usable negative space on the left for headline/copy
- best subjects: Chicago environment, store/floor, model wearing an actual stocked piece, or a strong in-store rack/detail
- avoid fake studio composites and generated skyline imagery

### 2. Homepage hero — mobile
- 1 portrait crop of the same shoot if possible
- 4:5 or 9:16
- subject should remain readable behind lower-left copy
- this is optional; desktop hero will crop automatically if it is not ready

### 3. Paradise Edit
- 1 real editorial/detail image
- 4:5 preferred
- can be extremely simple: leather detail, jewelry macro, back graphic, rack shot, full fit, store detail
- does not need to look like a professional campaign; intentional phone photography is better than synthetic art

### 4. Real product inventory
The homepage From the Feed, New Arrivals, editorial product slots, Quick View, collection pages and PDPs can all pull from Shopify product media.

For the first demo, prioritize at least 8 real products with:
- featured image
- vendor/designer
- title
- price
- size
- availability

For one-of-one / pre-owned pieces, also add when available:
- condition
- item state
- measurements
- flaws
- archive ID

## Product photography standard

For each important product, ideal minimum:
1. front
2. back
3. graphic/detail
4. brand/size tag
5. flaw/condition detail if used

Optional:
- fit/on-body
- packaging/accessories
- close material texture

Do not over-process the photos. Consistency comes from crop and UI, not pretending phone photography was shot in a studio.

## P1 — nice after the working demo

- 3 separate Paradise Features images
- store exterior/interior
- staff pick/on-body photography
- Chicago street/night editorial
- sold/archive item photography
- short vertical or landscape campaign video

## Fastest demo-content path

If time is tight:
1. import 8-12 real products into Shopify
2. upload one real hero photo
3. upload one real Paradise Edit photo
4. assign the best 6 products to From the Feed
5. let the rest of the theme pull from inventory automatically

That is enough for the site to feel like a real boutique instead of a generated concept deck.
